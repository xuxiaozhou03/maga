# ETF 排名与分析设计文档

**文档名称：** RANKING-AND-ANALYSIS.md  
**产品版本：** V0.6  
**文档状态：** 设计规范  
**适用对象：** Codex、开发人员

---

## 1. 设计目标

本模块负责将计算引擎生成的 ETF 特征转换为全池排名、市场分析和可读的特征结论。

核心目标：

1. 对整个 ETF 研究池进行横向比较。
2. 提供不同周期的收益排名。
3. 提供趋势、风险、成交活跃度和估值排名。
4. 生成 ETF 综合表现分析。
5. 生成市场整体状态分析。
6. 支持分类维度的动态筛选和统计。
7. 保证排名结果可解释、可追溯。

核心原则：

- 所有正式排名首先以整个 ETF 研究池为范围。
- 分类不影响全池排名。
- 原始指标和排名结果分开保存。
- 每项排名必须明确指标、方向、排名日期和有效样本数。
- 缺失值不参与排名。
- 不允许把不同量纲的原始指标直接相加。
- 不使用未来行情计算当前排名和结论。
- 排名不等于投资建议。

## 3. 排名通用规则

### 3.1 排名范围

所有正式排名以当日完整 ETF 研究池为范围。

例如研究池包含 23 只 ETF：

- 动量排名：在 23 只 ETF 中比较。
- 波动率排名：在有有效波动率数据的 ETF 中比较。
- 估值排名：在有对应估值数据的 ETF 中比较。
- 成交额排名：在有有效成交额数据的 ETF 中比较。

不同指标允许有不同的有效样本数量。

### 3.2 排名方向

| 排名类型  | 排名方向 | 原因                   |
| --------- | -------- | ---------------------- |
| 收益率    | 降序     | 收益越高越靠前         |
| 动量      | 降序     | 动量越强越靠前         |
| 波动率    | 升序     | 波动越低越靠前         |
| 最大回撤  | 升序     | 回撤越小越靠前         |
| 成交额    | 降序     | 成交额越大越靠前       |
| 溢价率    | 升序     | 溢价越低越靠前         |
| PE 百分位 | 升序     | 历史估值位置越低越靠前 |
| PB 百分位 | 升序     | 历史估值位置越低越靠前 |
| PS 百分位 | 升序     | 历史估值位置越低越靠前 |

注意：

- 最大回撤以负数保存。
- -5% 优于 -20%，因此按照数值升序排名并不适用。
- 最大回撤排名应按照绝对回撤由小到大排列，或者按照原始回撤值由大到小排列。
- 实现时统一采用原始最大回撤值降序。

例如：

| ETF | 最大回撤 | 排名 |
| --- | -------: | ---: |
| A   |      -5% |    1 |
| B   |     -10% |    2 |
| C   |     -20% |    3 |

### 3.3 排名计算

使用竞赛排名规则（Competition Ranking）：

- 不同数值按指定方向排序。
- 相同数值获得相同排名。
- 后续排名跳过已经占用的名次。

例如：

| ETF | 指标值 | 排名 |
| --- | -----: | ---: |
| A   |     10 |    1 |
| B   |     10 |    1 |
| C   |      8 |    3 |
| D   |      6 |    4 |

### 3.4 有效样本

只有满足以下条件的 ETF 才参与对应指标排名：

1. 指标值不为 null。
2. 指标值是有限数值。
3. 指标满足该指标的最低样本要求。
4. 数据质量状态允许参与排名。

不满足条件的 ETF：

- rank 为 null。
- 不参与有效样本总数。
- 保留原始特征和数据质量信息。

### 3.5 排名字段

统一使用：

```ts
interface MetricRanking {
  rank: number | null;
  total: number;
  value: number | null;
  direction: "asc" | "desc";
}
```

其中：

- rank：排名，1 开始。
- total：有效参与排名的 ETF 数量。
- value：参与排名的原始指标值。
- direction：排名方向。

排名日期使用每日分析结果的 `date`。

### 3.6 排名与原始指标分离

前端必须同时展示原始指标和排名。

例如：

```text
20 日收益：8.52%
20 日收益排名：第 3 / 23
```

不能只展示排名而隐藏原始指标。

## 4. 动量排名

### 4.1 排名指标

动量排名包括：

- 5 日收益。
- 20 日收益。
- 60 日收益。
- 120 日收益。
- 250 日收益。
- YTD 收益。

所有指标按收益率降序排列。

### 4.2 排名结构

```ts
interface MomentumRanking {
  d5: MetricRanking;
  d20: MetricRanking;
  d60: MetricRanking;
  d120: MetricRanking;
  d250: MetricRanking;
  ytd: MetricRanking;
}
```

### 4.3 动量解读

| 情况                     | 描述         |
| ------------------------ | ------------ |
| 多周期收益均为正         | 多周期上涨   |
| 短期和中期收益均为正     | 动量整体偏强 |
| 短期收益为负、中长期为正 | 短期回调     |
| 短期收益为正、中长期为负 | 短期反弹     |
| 多周期收益均为负         | 多周期走弱   |
| 短期收益明显高于中长期   | 短期动量增强 |
| 短期收益明显低于中长期   | 短期动量减弱 |

以上为描述性规则，不构成未来收益预测。

### 4.4 动量排名展示

ETF 全量列表至少支持：

- 5 日收益及排名。
- 20 日收益及排名。
- 60 日收益及排名。
- 120 日收益及排名。
- 250 日收益及排名。
- YTD 收益及排名。

用户切换排序字段时，按照对应指标动态排序。

## 5. 趋势排名与分析

### 5.1 趋势指标

趋势分析使用：

- MA5。
- MA10。
- MA20。
- MA60。
- MA120。
- MA250。
- 收盘价相对 MA20 的偏离程度。
- 收盘价相对 MA60 的偏离程度。
- 均线排列。
- 日、周、月 BOLL 形态。

### 5.2 均线偏离率

计算：

\[
Deviation_N = \frac{Close}{MA_N}-1
\]

重点输出：

- MA20 偏离率。
- MA60 偏离率。

解释：

- 大于 0：价格位于均线上方。
- 小于 0：价格位于均线下方。
- 绝对值越大：价格偏离均线越明显。

### 5.3 趋势描述

| 条件                     | 描述                   |
| ------------------------ | ---------------------- |
| 收盘价高于 MA20 和 MA60  | 价格处于中短期均线上方 |
| 收盘价低于 MA20 和 MA60  | 价格处于中短期均线下方 |
| MA20 高于 MA60           | 中期均线偏强           |
| MA20 低于 MA60           | 中期均线偏弱           |
| MA5、MA10、MA20 依次上升 | 短期均线多头排列       |
| MA5、MA10、MA20 依次下降 | 短期均线空头排列       |

趋势描述需要结合价格位置和均线排列，不得仅根据单一均线判断。

### 5.4 趋势排名

V0.6 不建立独立的加权趋势综合排名。

趋势模块提供：

- 原始均线数据。
- 均线偏离率。
- 均线排列状态。
- BOLL 形态。
- 可筛选的趋势标签。

不将这些不同类型的指标直接相加形成趋势分数。

## 6. 风险排名

### 6.1 波动率排名

使用：

- 20 日年化波动率。
- 60 日年化波动率。

排名方向：升序。

波动率越低，排名越靠前。

### 6.2 最大回撤排名

使用：

- 20 日最大回撤。
- 60 日最大回撤。
- 120 日最大回撤。

排名方向：原始最大回撤值降序。

例如：

- -5% 排在 -10% 前面。
- -10% 排在 -20% 前面。

### 6.3 风险分析

| 情况           | 描述                         |
| -------------- | ---------------------------- |
| 低波动、低回撤 | 近期波动和回撤相对较小       |
| 高波动、低回撤 | 波动较大，但区间回撤相对有限 |
| 低波动、高回撤 | 可能经历过持续缓慢下跌       |
| 高波动、高回撤 | 近期风险表现较高             |

风险排名只反映指定历史窗口，不代表未来风险一定较低。

### 6.4 风险排名展示

全量列表支持：

- 20 日波动率及排名。
- 60 日波动率及排名。
- 20 日最大回撤及排名。
- 60 日最大回撤及排名。
- 120 日最大回撤及排名。

## 7. 成交活跃度排名

### 7.1 排名指标

使用：

- 最新成交额。
- 5 日平均成交额。
- 20 日平均成交额。

其中主要排名指标为 20 日平均成交额。

### 7.2 排名方向

成交额越大，排名越靠前。

### 7.3 成交活跃度描述

| 条件                   | 描述                   |
| ---------------------- | ---------------------- |
| 5 日均额高于 20 日均额 | 近期成交活跃度上升     |
| 5 日均额低于 20 日均额 | 近期成交活跃度下降     |
| 5 日均额接近 20 日均额 | 近期成交活跃度相对稳定 |

### 7.4 成交额展示

必须明确单位为元。

前端可以格式化显示为：

- 万元。
- 百万元。
- 亿元。

格式化只影响显示，不改变 JSON 原始数值。

## 8. 溢价率分析

### 8.1 指标来源

使用研究池 ETF 基础信息中的最新溢价率。

### 8.2 排名方向

溢价率升序。

溢价率越低，排名越靠前。

### 8.3 溢价率说明

溢价率是 ETF 交易价格相对参考净值的偏离指标。

不能将溢价率简单理解为 ETF 的历史估值高低。

### 8.4 数据要求

- 溢价率缺失时不参与排名。
- 不允许将缺失值设置为 0。
- 需要记录溢价率数据的实际采集时间。
- 不同数据源口径不一致时不得混合排名。

### 8.5 注意事项

溢价率可能受跨境交易时差、市场交易状态和参考净值更新时间影响。

尤其是跨境 ETF，不能仅根据溢价率判断其是否值得买入。

## 9. 估值排名

### 9.1 估值指标

使用：

- PE。
- PB。
- PS。
- PE 历史百分位。
- PB 历史百分位。
- PS 历史百分位。
- DID（如数据源提供）。

### 9.2 估值排名

PE、PB、PS 分别排名。

排名指标使用对应的历史百分位：

| 指标          | 排名方向 |
| ------------- | -------- |
| PE 历史百分位 | 升序     |
| PB 历史百分位 | 升序     |
| PS 历史百分位 | 升序     |

百分位越低，说明当前估值在其近五年历史区间中所处位置越低。

### 9.3 估值解读

| 百分位    | 描述           |
| --------- | -------------- |
| 0～20%    | 近五年相对低位 |
| 20%～40%  | 近五年偏低     |
| 40%～60%  | 近五年中间区域 |
| 60%～80%  | 近五年偏高     |
| 80%～100% | 近五年相对高位 |

边界处理：

- 20% 归入偏低。
- 40% 归入中间区域。
- 60% 归入中间区域。
- 80% 归入偏高。

### 9.4 PE、PB、PS 分开分析

不同指数适用的估值指标不同。

例如：

- 盈利稳定的指数可以重点观察 PE。
- 资产类或金融类指数可以观察 PB。
- 部分成长型指数可以观察 PS。

不能要求每个 ETF 必须同时拥有 PE、PB、PS 才能参与估值分析。

### 9.5 DID

DID 单独展示：

- DID 原始值。
- DID 百分位（如果数据源提供）。
- DID 数据日期。

DID 不参与 PE、PB、PS 低估排名。

V0.6 不擅自定义 DID 的计算公式和估值含义。其业务定义以数据源实际字段说明为准。

### 9.6 估值数据日期

每项估值必须展示实际日期。

估值日期滞后时，应明确提示数据滞后。

不能把旧估值数据伪装成当日估值。

### 9.7 估值缺失

缺失估值：

- 不参与对应排名。
- 不影响其他估值类型。
- 在前端展示为暂无数据。
- 不填充 0。

## 10. BOLL 分析

### 10.1 分析周期

分别计算：

- 日 BOLL。
- 周 BOLL。
- 月 BOLL。

三个周期独立计算，不能将日 BOLL 数据直接转换为周 BOLL 或月 BOLL。

### 10.2 参数

统一使用：

- 周期：20。
- 标准差倍数：2。

计算公式和数据来源遵循 `CALCULATION-ENGINE.md`。

### 10.3 输出字段

```ts
interface BollingerAnalysis {
  middle: number | null;
  upper: number | null;
  lower: number | null;

  width: number | null;
  position: number | null;

  middleDirection: "up" | "down" | "flat" | "insufficient";

  widthChange: "expanding" | "contracting" | "stable" | "insufficient";

  shape: BollingerShape[];

  description: string[];
}

type BollingerShape =
  | "upper_breakout"
  | "lower_breakdown"
  | "upper_band_walk"
  | "lower_band_walk"
  | "middle_support"
  | "middle_resistance"
  | "expansion"
  | "contraction"
  | "neutral";
```

### 10.4 带宽

\[
Width = \frac{Upper-Lower}{Middle}
\]

中轨为 0 或数据缺失时返回 null。

### 10.5 中轨方向

使用当前中轨与前一有效周期中轨比较：

- 当前中轨高于前一周期：up。
- 当前中轨低于前一周期：down。
- 两者相等：flat。
- 缺少比较数据：insufficient。

### 10.6 带宽变化

使用当前带宽与前一有效周期带宽比较：

- 当前带宽明显增加：expanding。
- 当前带宽明显减少：contracting。
- 变化不明显：stable。
- 缺少数据：insufficient。

V0.6 使用相对变化阈值 5%：

```ts
const changeRatio = previousWidth > 0 ? currentWidth / previousWidth - 1 : null;
```

规则：

- 大于 5%：expanding。
- 小于 -5%：contracting。
- 介于 -5% 和 5%：stable。

### 10.7 BOLL 形态判断

#### 上轨突破

条件：

- 当前收盘价高于上轨。
- 前一有效周期收盘价不高于前一周期上轨。

描述：

价格向上突破布林带上轨。

#### 下轨跌破

条件：

- 当前收盘价低于下轨。
- 前一有效周期收盘价不低于前一周期下轨。

描述：

价格向下跌破布林带下轨。

#### 沿上轨运行

满足以下条件：

- 最近 3 个有效周期中至少 2 个收盘价位于中轨上方。
- 最近 3 个有效周期中至少 2 个收盘价接近或超过上轨。
- 中轨方向为 up。

描述：

价格沿布林带上轨附近运行，短期走势较强。

#### 沿下轨运行

满足以下条件：

- 最近 3 个有效周期中至少 2 个收盘价位于中轨下方。
- 最近 3 个有效周期中至少 2 个收盘价接近或低于下轨。
- 中轨方向为 down。

描述：

价格沿布林带下轨附近运行，短期走势较弱。

#### 中轨支撑

条件：

- 前一有效周期收盘价低于或接近中轨。
- 当前收盘价回到中轨上方。
- 当前收盘价没有突破上轨。

描述：

价格重新回到布林带中轨上方。

#### 中轨压力

条件：

- 前一有效周期收盘价高于或接近中轨。
- 当前收盘价回到中轨下方。
- 当前收盘价没有跌破下轨。

描述：

价格重新回到布林带中轨下方。

#### 扩口

带宽变化为 expanding。

描述：

布林带带宽扩大，近期价格波动范围增加。

#### 缩口

带宽变化为 contracting。

描述：

布林带带宽收窄，近期价格波动范围减小。

### 10.8 BOLL 形态阈值

“接近上轨或下轨”统一使用价格距离占带宽比例判断：

```ts
const upperDistance = (upper - close) / (upper - lower);

const lowerDistance = (close - lower) / (upper - lower);
```

- 距离上轨不超过带宽的 10%，视为接近上轨。
- 距离下轨不超过带宽的 10%，视为接近下轨。

如果带宽为 0 或数据无效，不生成对应形态。

### 10.9 形态优先级

一个周期可以同时具有多个形态。

例如：

- 沿上轨运行 + 带宽扩大。
- 中轨支撑 + 中轨向上。
- 沿下轨运行 + 带宽收窄。

形态输出顺序固定：

1. 上轨突破 / 下轨跌破。
2. 沿上轨运行 / 沿下轨运行。
3. 中轨支撑 / 中轨压力。
4. 扩口 / 缩口。
5. 中性。

如果没有其他形态，则输出 neutral。

### 10.10 日、周、月结论

三个周期分别生成形态和描述。

不得把日线形态直接作为周线或月线结论。

周 K 和月 K 按截至分析日期已形成的周期数据计算。

## 11. ETF 综合分析结论

### 11.1 结论目标

每只 ETF 生成简洁、客观、可解释的分析描述。

不生成买入、卖出或仓位建议。

### 11.2 结论结构

```ts
interface EtfAnalysisConclusion {
  performance: string[];
  trend: string[];
  risk: string[];
  liquidity: string[];
  valuation: string[];
  technical: {
    daily: string[];
    weekly: string[];
    monthly: string[];
  };
  summary: string[];
}
```

### 11.3 表现结论

根据：

- 5 日收益。
- 20 日收益。
- 60 日收益。
- 120 日收益。
- 250 日收益。
- YTD 收益。

生成多周期表现描述。

例如：

- 近期表现强于中期。
- 短期回调，中长期仍保持正收益。
- 多周期收益均为负。
- 近 20 日收益在研究池中排名靠前。

### 11.4 趋势结论

根据：

- 收盘价与均线关系。
- 均线排列。
- 均线偏离率。
- 日、周、月 BOLL 形态。

生成趋势描述。

例如：

- 收盘价位于 MA20 和 MA60 上方。
- 中期均线排列偏强。
- 日线出现上轨突破，周线仍处于中轨上方。
- 日线走弱，但月线趋势尚未改变。

### 11.5 风险结论

根据：

- 20 日波动率。
- 60 日波动率。
- 20 日最大回撤。
- 60 日最大回撤。
- 120 日最大回撤。
- 当前回撤。

生成风险描述。

例如：

- 近期波动率在研究池中较低。
- 60 日最大回撤相对较大。
- 当前仍处于历史高点回撤状态。

### 11.6 流动性结论

根据：

- 最新成交额。
- 5 日平均成交额。
- 20 日平均成交额。
- 成交活跃度变化。
- 全池成交额排名。

生成成交活跃度描述。

### 11.7 估值结论

根据：

- PE 历史百分位。
- PB 历史百分位。
- PS 历史百分位。
- 估值数据日期。

生成估值描述。

例如：

- PE 处于近五年相对低位。
- PB 处于近五年偏高区域。
- 当前缺少有效 PS 数据。

不得仅凭单一估值百分位得出 ETF 整体低估或高估结论。

### 11.8 综合描述

综合描述是前述客观特征的摘要，不是独立预测模型。

示例：

```text
近 20 日表现较强，短中期收益排名靠前。
收盘价位于 MA20 上方，日线 BOLL 呈扩口状态。
近期波动率处于研究池中等水平，60 日回撤较小。
PE 历史百分位处于近五年偏低区域。
```

所有描述必须能够追溯到具体指标。

如果数据不足，明确说明数据不足，不生成猜测性结论。

## 12. 市场整体分析

### 12.1 市场涨跌统计

统计：

- ETF 总数量。
- 有效行情数量。
- 上涨数量。
- 下跌数量。
- 平盘数量。
- 缺失行情数量。

上涨、下跌和平盘以分析日期最新有效日 K 的涨跌幅判断。

### 12.2 多周期收益统计

分别计算：

- 1 日。
- 5 日。
- 20 日。
- 60 日。
- 120 日。
- 250 日。
- YTD。

每个周期输出：

- 平均收益率。
- 中位数收益率。
- 正收益 ETF 数量。
- 负收益 ETF 数量。
- 平盘 ETF 数量。
- 有效样本数。

### 12.3 收益分布

市场收益分布建议使用固定区间：

| 区间       | 含义     |
| ---------- | -------- |
| 小于 -5%   | 明显下跌 |
| -5% 至 -2% | 下跌     |
| -2% 至 0%  | 小幅下跌 |
| 0% 至 2%   | 小幅上涨 |
| 2% 至 5%   | 上涨     |
| 大于 5%    | 明显上涨 |

每个区间统计 ETF 数量和占比。

区间左闭右开，最后一个区间包含上界。

### 12.4 趋势分布

统计：

- 收盘价高于 MA20 的 ETF 数量和占比。
- 收盘价高于 MA60 的 ETF 数量和占比。
- MA20 高于 MA60 的 ETF 数量和占比。
- 多头排列数量。
- 空头排列数量。
- 均线排列混合数量。

### 12.5 风险分布

统计：

- 20 日波动率分布。
- 60 日波动率分布。
- 60 日最大回撤分布。
- 当前回撤分布。

### 12.6 估值分布

PE、PB、PS 分开统计：

- 有效 ETF 数量。
- 平均百分位。
- 中位数百分位。
- 低位 ETF 数量。
- 高位 ETF 数量。

估值缺失不参与对应统计。

### 12.7 市场结论

市场结论采用规则驱动方式。

V0.6 不使用生成式 AI 自动推断市场结论，也不建立不可解释的市场评分。

示例规则：

| 观察情况                              | 市场描述             |
| ------------------------------------- | -------------------- |
| 上涨 ETF 占比明显高于下跌 ETF         | 市场上涨广度较高     |
| 下跌 ETF 占比明显高于上涨 ETF         | 市场下跌广度较高     |
| 20 日平均收益为正且高于 60 日平均收益 | 近期市场动量有所增强 |
| 20 日平均收益为负且低于 60 日平均收益 | 近期市场动量有所减弱 |
| 大多数 ETF 位于 MA20 上方             | 短期市场趋势偏强     |
| 大多数 ETF 位于 MA20 下方             | 短期市场趋势偏弱     |
| 多数 ETF 波动率上升                   | 市场波动水平有所增加 |

这里的“大多数”统一定义为有效样本占比超过 60%。

市场结论必须注明统计样本数量。

不能因为单个 ETF 上涨或下跌就判断整个市场状态。

## 13. 分类表现分析

### 13.1 分类分析原则

分类仅用于展示、筛选和统计。

分类不影响：

- 全池排名。

### 13.2 分类统计

动态计算：

- 分类 ETF 数量。

- 5 日收益。

## 16. 综合评分决策

### 16.1 V0.6 不启用加权综合评分

V0.6 不设置一个人为综合权重，将动量、趋势、风险、估值和成交活跃度直接合成为单一分数。

原因：

1. 不同指标的量纲不同。
2. 指标之间可能高度相关。
3. 不同市场环境下指标有效性可能不同。
4. 权重缺乏历史验证时容易产生误导。
5. 单一综合分数会掩盖 ETF 的真实特征。

### 16.2 V0.6 的替代方式

使用多维排名和特征组合展示：

```text
ETF A
├── 动量：20 日排名第 3
├── 趋势：价格位于 MA20 上方
├── 风险：20 日波动率排名第 5
├── 回撤：60 日最大回撤排名第 2
├── 成交：20 日平均成交额排名第 4
└── 估值：PE 历史百分位排名第 8
```

这样可以看出 ETF 在不同维度的表现，不需要将其压缩为一个缺乏解释的分数。

### 16.3 后续综合评分研究

未来如果需要综合评分，必须先完成：

1. 指标相关性分析。
2. 不同市场环境下的指标表现分析。
3. 不同指标对未来 5、20、60 日收益的预测能力分析。
4. 历史样本外验证。
5. 权重敏感性分析。
6. 与单项排名进行对比。

未经验证的权重不能进入正式排名。

## 17. 防止未来数据泄漏

所有排名和分析结论必须使用分析日期及之前的数据。

具体要求：

- 收益只使用分析日期及之前的收盘价。
- BOLL 只使用截至分析日期的 K 线。
- 估值只使用不晚于分析日期的记录。
- 成交额只使用已完成交易日的数据。
- 分类只使用分析日期对应的分类快照。
- 历史排名只使用历史快照。

未来收益数据不得进入当前排名和当前结论。

## 18. 验收标准

### 18.1 排名

- 能生成 5、20、60、120、250 日及 YTD 收益排名。
- 能生成 20、60 日波动率排名。
- 能生成 20、60、120 日最大回撤排名。
- 能生成成交额排名。
- 能生成溢价率排名。
- 能生成 PE、PB、PS 历史百分位排名。
- 排名方向正确。
- 同值采用竞赛排名。
- 缺失值不参与排名。
- 每项排名记录有效样本数。

### 18.2 趋势

- 能计算均线偏离率。
- 能判断均线排列。
- 能输出日、周、月 BOLL。
- 能识别上轨突破、下轨跌破。
- 能识别沿轨运行。
- 能识别中轨支撑和压力。
- 能识别扩口和缩口。

### 18.3 ETF 结论

- 能生成表现描述。
- 能生成趋势描述。
- 能生成风险描述。
- 能生成成交活跃度描述。
- 能生成估值描述。
- 能生成日、周、月技术描述。
- 每条结论都能追溯到具体指标。
- 数据不足时不生成猜测性结论。

### 18.4 市场分析

- 能统计涨跌数量。
- 能计算多周期收益分布。
- 能计算趋势分布。
- 能计算风险分布。
- 能计算估值分布。
- 能生成市场描述性结论。
- 每项统计保留有效样本数。

### 18.5 分类分析

- 分类筛选不改变全池排名。
- 分类内部可以动态排序。
- 分类统计使用有效 ETF 样本。
- 待确认分类不参与已确认分类统计。

### 18.6 数据一致性

- 历史排名读取对应日期快照。
- 当前排名使用当前研究池。
- 历史分类使用历史分类快照。
- 不使用未来数据。
- 不生成未经确认的综合评分。
