**文档名称：** FRONTEND.md  
**产品版本：** V0.6  
**文档状态：** 设计规范  
**适用对象：** Codex、前端开发人员

---

## 1. 前端目标

前端是 ETF 分析系统的数据展示层。

核心目标：

1. 展示整个 ETF 研究池的表现排名。
2. 快速了解市场整体状况。
3. 对比不同 ETF 的收益、风险、趋势、成交和估值表现。
4. 按分类筛选 ETF，并动态计算分类表现。
5. 查看历史日期的分析结果。

前端不负责行情采集和正式特征计算，只负责读取计算任务生成的 JSON 并展示。

### 1.1 页面范围

V0.6 只实现三个页面：

| 页面         | 路由          | 说明                              |
| ------------ | ------------- | --------------------------------- |
| ETF 全量列表 | `/etfs`       | 默认首页，展示全池排名和 ETF 表现 |
| 市场概览     | `/market`     | 展示市场整体表现                  |
| 分类表现     | `/categories` | 展示分类统计和分类内 ETF 排名     |

默认进入 `/etfs`。

### 1.2 不建设的页面

V0.6 不建设：

- ETF 详情页。
- 独立研究报告页。
- 独立估值分析页。
- ETF 管理后台。
- 在线分类审批页面。
- 策略编辑页面。
- 回测页面。

所有 ETF 的分析信息直接在全量列表中展示，不通过点击进入详情页。

| 数据校验        | Zod             |

### 2.2 UI 设计原则

整体采用桌面端优先的金融数据分析工具风格。

要求：

- 信息密度适中。
- 以表格为主要信息载体。
- 关键指标使用颜色辅助识别。
- 复杂数据通过图表展示。
- 不使用大面积装饰性卡片。
- 不使用过多渐变和动画。
- 不追求营销型 Dashboard 风格。
- 页面重点放在数据对比和快速识别上。

### 2.3 数值颜色

收益类指标：

| 情况   | 展示         |
| ------ | ------------ |
| 正收益 | 红色         |
| 负收益 | 绿色         |
| 零收益 | 默认文字颜色 |
| 缺失值 | `--`         |

风险类指标：

风险数值不直接套用收益颜色规则。

例如：

- 波动率越高，风险越高。
- 最大回撤越大，风险越高。
- 最大回撤以负数保存，数值越接近 0，回撤越小。

估值百分位：

- 百分位低：使用偏积极的低估值颜色。
- 百分位高：使用偏警示的高估值颜色。
- 颜色仅表达历史相对位置，不代表买卖建议。

所有颜色必须同时保留实际数值，不能只依赖颜色传达含义。

### 3.2 侧边导航

导航固定三个入口：

1. 市场概览
2. ETF 全量列表
3. 分类表现

默认选中 ETF 全量列表。

### 3.4 历史日期选择

支持查看已有的历史分析结果。

交互规则：

1. 默认加载 `current.json`。
2. 用户选择历史日期后，加载对应的 `daily/{date}.json`。
3. 切换页面时保留当前选择的分析日期。
4. 选择最新日期时重新加载 `current.json`。
5. 历史日期没有数据时展示空状态。
6. 不允许用户选择未来日期。

历史日期列表可以根据已经存在的每日文件索引生成，也可以由后续版本增加日期索引文件。V0.6 不要求建设独立历史数据库。

## 4. 数据加载

### 4.1 默认数据

默认请求：

```text
/data/current.json
```

历史数据：

```text
/data/daily/{YYYYMMDD}.json
```

实际请求路径必须使用：

```ts
`${import.meta.env.BASE_URL}data/current.json`;
```

避免静态部署在子路径时出现资源路径错误。

### 4.2 数据加载模块

统一封装数据加载，不允许每个页面重复实现 fetch。

建议接口：

```ts
interface AnalysisDataLoader {
  loadCurrent(): Promise<DailyAnalysisResult>;

  loadByDate(date: number): Promise<DailyAnalysisResult>;
}
```

### 4.3 数据加载状态

统一处理：

- loading：数据加载中。
- success：数据加载成功。
- empty：数据为空。
- error：数据加载失败。

加载失败时展示明确错误信息和重试操作。

不能在请求失败时静默展示旧数据，并让用户误以为是最新结果。

### 4.4 数据校验

读取 JSON 后使用共享 Zod Schema 校验。

校验失败：

- 不渲染不符合结构的数据。
- 显示数据格式异常提示。
- 在开发环境输出具体错误路径。

## 5. 页面一：ETF 全量列表

### 5.1 页面定位

这是系统默认首页，也是最核心的页面。

主要回答：

- 当前哪些 ETF 表现更好？
- 哪些 ETF 动量更强？
- 哪些 ETF 风险更低？
- 哪些 ETF 成交更活跃？
- 哪些 ETF 估值处于历史低位？

展示整个研究池中的 ETF，不因为分类而改变全池排名。

### 5.2 页面结构

```text
┌──────────────────────────────────────────────────────────┐
│ ETF 全量列表                                              │
│ 全部研究池 ETF 的表现、风险、趋势、成交和估值排名         │
├──────────────────────────────────────────────────────────┤
│ ETF 总数  上涨数量  下跌数量  平均收益  中位数收益         │
├──────────────────────────────────────────────────────────┤
│ 分类筛选：全部  宽基  行业  主题  策略  商品  其他资产      │
├──────────────────────────────────────────────────────────┤
│ 搜索 ETF    排名维度    收益周期    更多筛选               │
├──────────────────────────────────────────────────────────┤
│ ETF 列表                                                    │
│                                                          │
│ 名称  分类  规模  20日收益  60日收益  波动率  回撤  排名    │
│ ...                                                      │
└──────────────────────────────────────────────────────────┘
```

### 5.3 顶部统计

展示全池概览：

| 指标       | 数据来源                |
| ---------- | ----------------------- |
| ETF 总数   | 有效研究池数量          |
| 上涨数量   | 最新分析日上涨 ETF 数量 |
| 下跌数量   | 最新分析日下跌 ETF 数量 |
| 平均收益   | 全池指定周期收益均值    |
| 中位数收益 | 全池指定周期收益中位数  |

默认收益周期为 20 日。

顶部统计始终基于当前筛选范围：

- 选择全部时统计全池。
- 选择某个一级分类时统计该一级分类。
- 选择某个二级分类时统计该二级分类。

### 5.4 分类筛选

支持：

- 全部。
- 一级分类。
- 二级分类。

分类体系以 `categories.json` 为准。

分类筛选只改变列表数据范围，不改变 ETF 已保存的全池排名。

例如：

```ts
const filteredEtfs = result.etfs.filter((etf) => {
  if (!selectedCategoryId) {
    return true;
  }

  return etf.category.categoryId === selectedCategoryId;
});
```

待确认分类的 ETF：

- 在全部列表中正常展示。
- 分类显示为待确认。
- 不归入任何已确认二级分类。
- 选择具体分类时不参与该分类结果。

### 5.5 搜索

支持按以下字段搜索：

- ETF 名称。
- ETF 代码。
- 跟踪指数名称。
- 跟踪指数代码。

搜索采用前端本地过滤，不请求服务器。

### 5.6 排名维度

提供排名维度选择：

| 排名维度   | 默认排序             | 排名字段         |
| ---------- | -------------------- | ---------------- |
| 动量       | 降序                 | 收益率           |
| 风险       | 升序或按回撤原值降序 | 波动率、最大回撤 |
| 成交活跃度 | 降序                 | 20 日平均成交额  |
| 溢价率     | 升序                 | premiumRate      |
| PE 估值    | 升序                 | PE 历史百分位    |
| PB 估值    | 升序                 | PB 历史百分位    |
| PS 估值    | 升序                 | PS 历史百分位    |

DID 仅展示原始值和上游百分位（若有），不纳入低估排名。

排名结果直接使用每日 JSON 保存的排名字段，不在前端重新计算正式全池排名。

### 5.7 动量周期

动量维度支持：

- 5 日。
- 20 日。
- 60 日。
- 120 日。
- 250 日。
- YTD。

切换周期时：

- 更新当前排序字段。
- 显示对应周期收益率。
- 显示对应周期全池排名。
- 不改变其他维度的数据。

### 5.8 风险维度

风险维度支持：

- 20 日波动率。
- 60 日波动率。
- 20 日最大回撤。
- 60 日最大回撤。
- 120 日最大回撤。

波动率按升序。

最大回撤按原始数值降序，例如：

- -5% 排在 -10% 前面。
- -10% 排在 -20% 前面。

不能对最大回撤取绝对值后再进行降序排名。

### 5.9 表格字段

采用分组表头，避免单行表格字段过多。

#### 基础信息

#### 趋势表现

#### 风险表现

| 字段           | 说明              |

| 20 日最大回撤  | 近 20 日最大回撤  |

#### 成交表现

### 5.10 表格展示规则

字段较多，采用分组表头和横向滚动。

默认展示列：

- 排名。
- ETF 名称。
- ETF 代码。
- 二级分类。
- 20 日收益。
- 60 日收益。
- 250 日收益。
- 20 日波动率。
- 60 日最大回撤。
- 20 日平均成交额。
- PE 百分位。
- PB 百分位。

其余字段通过列显示设置展开。

列显示设置只影响前端，不修改数据。

### 5.11 排序规则

支持：

- 点击表头切换升序/降序。
- 通过排名维度选择切换默认排序。
- 通过周期选择切换收益排序字段。

排序必须稳定。

同值时使用 ETF 代码升序作为第二排序条件。

缺失值：

- 默认排在列表末尾。
- 升序和降序均不改变缺失值位于末尾的规则。

前端临时排序不覆盖 JSON 中保存的正式排名。

### 5.12 ETF 行信息

每行展示：

- ETF 名称。
- ETF 代码。
- 跟踪指数。
- 分类。
- 核心指标。
- 主要趋势结论。

允许在行内展示简短的结论标签，例如：

- 多周期上涨。
- 日线走强。
- 波动较高。
- 回撤较小。
- 估值低位。

标签必须来自每日结果中保存的分析结论，不在前端重新推断。

不点击跳转详情页。

## 6. 页面二：市场概览

### 6.1 页面定位

市场概览用于观察整个 ETF 研究池的整体表现。

重点回答：

- 当前 ETF 市场整体上涨还是下跌？
- 收益分布如何？
- 当前趋势结构如何？
- 风险水平如何？
- 估值处于什么位置？

### 6.2 页面结构

```text
┌──────────────────────────────────────────────────────────┐
│ 市场概览                                                  │
├──────────────────────────────────────────────────────────┤
│ ETF 总数  上涨数量  下跌数量  平均收益  中位数收益         │
├──────────────────────────────────────────────────────────┤
│ 市场收益分布                                              │
│                                                          │
│ 收益区间分布图                                            │
├──────────────────────────────────────────────────────────┤
│ 趋势结构                                                  │
│                                                          │
│ 多头排列  空头排列  震荡  日线/周线/月线                   │
├──────────────────────────────────────────────────────────┤
│ 风险结构                                                  │
│                                                          │
│ 波动率分布  最大回撤分布                                   │
├──────────────────────────────────────────────────────────┤
│ 估值结构                                                  │
│                                                          │
│ PE/PB/PS 百分位分布                                       │
├──────────────────────────────────────────────────────────┤
│ 市场结论                                                  │
└──────────────────────────────────────────────────────────┘
```

### 6.3 市场核心指标

展示：

- ETF 总数。
- 上涨数量。
- 下跌数量。
- 平均收益。
- 中位数收益。
- 上涨比例。
- 下跌比例。

默认收益周期为 20 日。

支持切换：

- 5 日。
- 20 日。
- 60 日。
- 120 日。
- 250 日。
- YTD。

切换周期后，所有依赖收益周期的统计同步更新。

### 6.4 收益分布

使用 ECharts 展示收益率区间分布。

建议区间：

- 小于 -10%。
- -10% 至 -5%。
- -5% 至 -2%。
- -2% 至 0%。
- 0% 至 2%。
- 2% 至 5%。
- 5% 至 10%。
- 大于 10%。

统计当前周期有效收益率的 ETF 数量。

缺失收益率的 ETF 不参与分布统计。

图表展示数量和占比。

### 6.5 趋势结构

分别展示日线、周线、月线趋势分布。

每个周期至少展示：

- 多头排列数量。
- 空头排列数量。
- 震荡或其他状态数量。
- 有效样本数量。

使用环形图或横向条形图。

趋势分类以计算引擎生成的标准趋势状态为准，不允许前端自行判断均线排列。

### 6.6 风险结构

展示：

- 20 日波动率分布。
- 60 日波动率分布。
- 20 日最大回撤分布。
- 60 日最大回撤分布。

使用区间统计图。

缺失风险指标的 ETF 不参与对应统计。

### 6.7 估值结构

分别展示 PE、PB、PS 历史百分位分布。

建议区间：

- 0%～20%。
- 20%～40%。
- 40%～60%。
- 60%～80%。
- 80%～100%。

同时展示：

- 有效样本数量。
- 平均百分位。
- 中位数百分位。
- 低于 20% 的数量。
- 高于 80% 的数量。

不同估值类型独立统计。

缺失估值不参与统计。

### 6.8 市场结论

展示计算任务生成的市场描述性结论。

例如：

- 当前研究池整体收益表现。
- 上涨与下跌结构。
- 多周期趋势结构。
- 市场风险分布。
- 估值分布。

结论必须来源于 `market` 数据，不允许前端生成新的市场判断。

## 7. 页面三：分类表现

### 7.1 页面定位

分类表现用于比较不同 ETF 分类的整体表现，以及分类内部 ETF 的表现。

分类仅是观察维度，不影响全池排名和特征计算。

### 7.2 页面结构

```text
┌──────────────────────────────────────────────────────────┐
│ 分类表现                                                  │
├──────────────────────────────────────────────────────────┤
│ 一级分类                                                  │
│ 宽基指数 行业指数 主题指数 策略指数 商品指数 其他资产      │
├──────────────────────────────────────────────────────────┤
│ 二级分类                                                  │
│ A股核心宽基 A股中小盘宽基 美股宽基 港股宽基                │
├──────────────────────────────────────────────────────────┤
│ 分类统计                                                  │
│ ETF 数量  平均收益  中位数收益  上涨比例  平均波动率        │
├──────────────────────────────────────────────────────────┤
│ 分类对比                                                  │
│                                                          │
│ 各二级分类收益表现                                        │
├──────────────────────────────────────────────────────────┤
│ 分类 ETF 列表                                             │
│                                                          │
│ 排名  ETF 名称  收益  风险  成交  估值                      │
└──────────────────────────────────────────────────────────┘
```

### 7.3 分类选择

支持一级分类和二级分类。

交互：

1. 默认展示所有一级分类。
2. 选择一级分类后，展示其下属二级分类。
3. 选择二级分类后，展示该分类的 ETF 列表。
4. 允许返回全部分类。
5. 分类顺序按照 `categories.json` 配置顺序。

### 7.4 分类统计

分类统计在前端动态计算。

统计指标：

| 指标         | 计算方式                  |
| ------------ | ------------------------- |
| ETF 数量     | 当前分类 ETF 数量         |
| 平均收益     | 当前周期收益率算术平均值  |
| 中位数收益   | 当前周期收益率中位数      |
| 上涨数量     | 收益率大于 0 的数量       |
| 下跌数量     | 收益率小于 0 的数量       |
| 上涨比例     | 上涨数量 / 有效收益样本数 |
| 平均波动率   | 有效波动率算术平均值      |
| 平均最大回撤 | 有效最大回撤算术平均值    |

收益周期支持：

- 5 日。
- 20 日。
- 60 日。
- 120 日。
- 250 日。
- YTD。

缺失值不参与统计。

### 7.5 分类对比

展示当前一级分类下各二级分类的表现。

默认对比指标：

- 20 日平均收益。
- 60 日平均收益。
- 250 日平均收益。
- 上涨比例。
- 平均波动率。

支持切换对比指标。

图表使用 ECharts 横向条形图。

分类样本数量同时展示，避免仅凭少量 ETF 的平均收益得出误导性结论。

### 7.6 分类内部 ETF 列表

复用 ETF 全量列表的表格组件。

默认排序：

- 20 日收益降序。

支持切换：

- 动量。
- 风险。
- 成交活跃度。
- PE 估值。
- PB 估值。
- PS 估值。

展示字段和全量列表保持一致。

### 7.7 分类统计边界

- 待确认分类不参与已确认分类统计。
- 一个 ETF 只能属于一个二级分类。
- 不允许重复计入多个分类。
- 分类变更不影响全池排名。
- 分类变更不触发计算任务。
- 分类统计只使用当前分析结果中的 ETF 数据。

## 10. 数值格式化

统一实现格式化函数。

### 10.1 收益率

内部收益率以小数保存。

展示时乘以 100。

示例：

```ts
formatPercent(0.125); // 12.50%
formatPercent(-0.035); // -3.50%
```

### 10.2 成交额

根据数值大小使用：

- 元。
- 万元。
- 亿元。

展示时保留合理小数位。

### 10.3 规模

ETF 规模统一展示为：

- 万元。
- 亿元。

### 10.4 估值百分位

内部以 0～1 保存。

展示时转换为百分比。

示例：

```ts
formatPercent(0.7376); // 73.76%
```

### 10.5 缺失值

统一显示：

```text
--
```

不得将 null 格式化成 0。

## 12. 响应式要求

### 12.1 桌面端

优先保证桌面端完整体验。

- 左侧导航固定。
- 内容区自适应。
- ETF 表格支持横向滚动。
- 图表使用合理的网格布局。

### 12.2 平板端

- 导航可以折叠。
- 统计卡片自动换行。
- 图表调整为单列或双列。
- 表格允许横向滚动。

### 12.3 手机端

- 导航收缩为移动端菜单。
- 统计卡片使用两列布局。
- 图表单列展示。
- ETF 表格保留横向滚动。
- 核心字段优先展示。

不要求 V0.6 专门建设移动端独立页面。

## 13. 性能要求

- 页面首次加载只请求必要的 JSON。
- 不重复请求相同日期的数据。
- 页面切换时复用已加载数据。
- 分类筛选不重新请求 JSON。
- 排序不重新请求 JSON。
- ECharts 不重复创建实例。
- ETF 列表支持合理的渲染性能优化。
- 大量结论文本不默认全部展开。

当前研究池规模下，不需要引入复杂虚拟列表系统；如果实际数据量导致明显卡顿，再增加虚拟滚动。

## 15. 开发约束

1. 页面和组件使用 TypeScript。
2. 不允许使用 `any` 绕过数据类型。
3. 不允许在页面中直接散落 JSON 请求代码。

6. 不允许为了分类页面复制一套 ETF 表格。
7. 不允许增加产品范围以外的页面。
8. 不允许引入 Next.js 或后端 API。
9. UI 使用项目现有 shadcn/ui Base UI 组件体系。
